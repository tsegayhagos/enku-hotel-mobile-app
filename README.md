# Enku Hotel & Resort - Guest & Online Booking Mobile App

A modern, high-end cross-platform mobile application (iOS & Android) built with **React Native**, **Expo (SDK 52)**, and **TypeScript** for the Enku Hotel Management SaaS ecosystem.

---

## 🌟 Core Mobile App Features

1. **🏨 Explore & Discover:**
   - Grand Enku Resort hero showcase with special discounts.
   - Live availability lookup by check-in / check-out dates and guest capacity.
   - Quick 1-tap shortcuts for Dining, Laundry, Housekeeping, and Digital Key.

2. **🛏️ Room Catalog & Instant Online Booking:**
   - Catalog of suites and rooms (Deluxe, Executive, Presidential Villa, Standard).
   - Rich amenity tags (King bed, Jacuzzi, Balcony, Minibar, WiFi).
   - 3-step checkout with **Telebirr**, **CBE Birr**, and card options.
   - Instant digital reservation voucher generation.

3. **🛎️ In-Stay Concierge & Room Services:**
   - **Restaurant & Bar POS:** Order food (Tibs, Pizza, Traditional Habesha Coffee) directly to room with live order prep tracker.
   - **Valet Laundry Service:** Schedule dry cleaning, garment wash, and Express 3-hour turnaround (+50%).
   - **Housekeeping on Demand:** 1-tap calls for room make-up, extra towels, pillows, and toiletries.
   - **Maintenance Helpdesk:** Direct instant reporting for AC, plumbing, or lighting issues.

4. **🔑 Digital Room Key & Live Folio Billing:**
   - Interactive Digital Key (Simulated NFC/Tap-to-unlock) for Room 204.
   - Real-time transparent itemized breakdown of room rate, restaurant charges, laundry, and 15% VAT.
   - 1-tap express digital check-out with Telebirr and CBE Birr.

5. **👤 Guest Profile & Multi-Language:**
   - Past booking history.
   - Enku Gold VIP tier loyalty badge.
   - Multi-language switcher: **አማርኛ (Amharic)**, **ትግርኛ (Tigrinya)**, **English**.
   - 24/7 Hotel concierge hotline & airport shuttle request.

## 🚀 How to Run the Mobile App

### 1. Install Dependencies
```bash
cd mobile
npm install
```

### 2. Start the Expo Development Server
```bash
npm start
```

### 3. Open on Your Phone (Android / iPhone)
1. Download **Expo Go** from Google Play Store or Apple App Store.
2. Scan the QR code displayed in your terminal with the Expo Go app (Android) or Camera app (iOS).
3. The app will immediately load on your physical phone!

### 4. Open in Web Browser (Instant Preview)
```bash
npm run web
```
